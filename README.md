## 交互原型

`prototype/index.html` 是 spec 阶段的可交互原型（v0.3），覆盖 REQ-001～003 的首发体验：Onboarding 与权限引导、按住说话与录音提示、插入规则与修复入口、智能整理设置、词典（含从用户修改中静默学习专有词）与历史。直接用浏览器打开即可，不需要安装或联网；右侧"演示设置"面板用于切换场景和模拟系统权限、模型下载、OpenRouter 结果，"原型说明"页列出全部 20 个验收场景的操作方法。

原型里的识别和整理结果是预设句子，不代表真实模型效果。领域规则在 `prototype/domain.js`，可用 `node prototype/tests/domain.test.js` 运行状态测试。场景映射、验证证据和原型限制写在各 Requirement 产品上下文的"原型 baseline"一节。

## 测试版说明

首发只做测试版（REQ-001 DEC-018）：用固定的自签名身份签名，不做 Apple 公证，测试者第一次打开时需要在"系统设置 › 隐私与安全性"中允许打开。闪说只申请麦克风和辅助功能两项权限，不申请输入监控（DEC-017）。

性能与准确率只在开发机（Apple M5、16 GB、macOS 26.4.1）上测试，**未在 M1 等较老机型上测试，较老机型上的识别延迟可能更高**（DEC-019）。

已知准确率限制：120 条公开夹具的完整生产复测中，中文 CER 6.48%（目标 ≤ 6%）、混说 MER 12.94%（目标 ≤ 10%）未达标；英文 WER 6.03%（目标 ≤ 8%）达标。首个 `v0.1.0-beta.1` 按 DEC-024 接受这两项限制，原 NFR-003 仍未通过。中文原生与 Python 运行时差异尚未解决；完整方法、环境和原始结果见 [ASR 验证报告](docs/validation/asr-rms-fix-125650.md)。

## 安装测试版

`v0.1.0-beta.1` 提供 arm64 的 ZIP、DMG 和 `SHA256SUMS.txt`；应用版本为 `0.1.0`。下载见 [测试版发布页](https://github.com/arnow117/voice-dictation/releases/tag/v0.1.0-beta.1)。测试版使用项目测试签名，未经过 Apple 公证，首次打开可能需要在 macOS“隐私与安全性”中明确允许。安装步骤、权限说明和模型下载行为见 [安装说明](docs/install.md)，未完成验证与质量限制见 [已知问题](docs/known-issues.md)。

当前安装包只含 REQ-001 的本地听写。MiniMax 是后续 REQ-002 整理的已选方向，尚未接入应用或安装包；个人词典也尚未接入。

已确认的兼容性限制：本安装版在备忘录可正常听写输入；Codex 聊天输入框尚不能自动写入，可先在备忘录听写后手动复制。完整矩阵和后续项见已知问题清单。

## 当前核心闭环（开发构建）

运行 `bash scripts/test.sh` 会执行 Swift 单元测试、构建默认 ad-hoc 开发 `.app`，然后使用本地 ASR 夹具进行冒烟检查。发布脚本才明确使用项目测试签名。正常启动菜单栏应用时只采集麦克风输入；`--transcribe <wav>` 是显式的开发/测试 CLI，不是产品运行路径。

应用需要麦克风权限。授予辅助功能权限后，默认按住 Fn 录音；松开后在确认过的同一可编辑目标中直接插入。未授予辅助功能权限时，按住 ⌃⇧ Space 进入仅复制模式，结果写入剪贴板，由用户自行粘贴。应用不会请求输入监控权限。

录音胶囊和菜单栏状态先变为“正在录音”才开始采集。按 Esc、在按住快捷键时再按其他键、进入安全输入框、系统睡眠/锁屏、麦克风或直接插入权限被撤销，都会立即丢弃本次会话。短于 0.3 秒的按压丢弃；单次录音最多 3 分钟，最后 15 秒显示倒计时。焦点变化、未知或不可编辑时会复制而不会向新目标模拟输入。

为诊断本机性能，应用还会在 Application Support/Shanshuo/PerformanceDiagnostics 保存有界的 owner-only 类型化事件。事件仅含随机标识、固定事件/结果、单调时间和必要音频时长，不含听写内容、应用或窗口名称、剪贴板、URL、路径和错误详情，也不会上传。真机测量步骤、夹具来源和不会误报 PASS 的汇总工具见 [bench/e2e/README.md](bench/e2e/README.md)。

## 首次设置、暂停与历史

首次启动会打开原生设置窗口，也可以从菜单栏的“继续设置…”返回。流程依次包含欢迎、麦克风、辅助功能、模型、麦克风测试、快捷键、练习和完成。模型下载时可以继续完成不依赖模型的步骤；模型、权限和有效快捷键仍会在完成前实时复查。

麦克风测试只显示实时音量，使用与听写互斥的内存采集，不保存或识别录音。输入设备可以跟随系统默认值，或选择稳定设备 UID；选择会在下一次采集开始时固定。菜单栏的“设置…”可选择 Fn、右 Option、单修饰键或自定义修饰键加普通键组合；录入时会暂时停止全局触发，未授予辅助功能时仍固定为仅复制的 ⌃⇧ Space。Fn 的系统占用状态无法自动确认，设置会提供键盘设置入口，仍须完成一次真实按住/松开测试。提示音开关只影响开始录音的声音，胶囊和菜单栏状态始终显示。

菜单栏可暂停一小时或恢复语音输入。历史默认开启，最多保留七天，保存在 `~/Library/Application Support/Shanshuo/History/history.sqlite`；历史窗口可复制、删除单条、清空或关闭后续保存。练习文字和音频始终只在内存中，练习会话不会写入历史。隐私窗口会显示实际本地路径和当前历史开关。

## 语音模型

菜单栏的“管理语音模型…”打开原生模型窗口。首版只提供 **Qwen3-ASR 0.6B（INT8）**：首次使用从 Hugging Face 下载，失败时可切换到 hf-mirror；窗口可暂停、继续、重试、修复和删除应用下载的模型。每个文件会流式写入 `.part`，按固定 revision、大小和 SHA-256 校验，通过后才原子替换为正式文件并加载运行时。

生产模型目录是 `~/Library/Application Support/Shanshuo/Models/qwen3-asr-0.6b-int8`。`SHANSHUO_MODEL_DIR` 只供开发和测试读取已有缓存；模型窗口不会删除、修复或写入该目录。下载、校验、加载或删除期间，应用不接受新的听写，会丢弃正在进行的会话。

以下真实系统检查尚未作为本轮自动化结果记录，需在已授权的 macOS 测试账户中执行：

- 在 TextEdit 或备忘录中确认 Fn 录音时，非激活胶囊和菜单栏同步显示，且目标应用不失焦。
- 在未授权辅助功能的状态下确认 ⌃⇧ Space 只复制；授权后确认直接插入、焦点变化复制、Esc 与安全输入丢弃。
- 在终端确认包含换行的文本只复制，不发送 Return；在全屏应用和多显示器上确认胶囊位置。
- 在目标应用矩阵中检查 AX、粘贴回退和剪贴板恢复；这些兼容性与性能指标由 T015 验收。
