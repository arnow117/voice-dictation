# 应用兼容性

首个公开测试版按 REQ-001 DEC-023，在开发机的八个已安装应用中验证。
每个应用计划做十次正式版听写，实测总插入成功率要求至少 98%。
识别器单测、模拟插入器或旧探测应用的结果不计入该成功率。

下表是验证范围，尚未完成正式版真实听写测试，不能视为兼容性通过声明。
最终结果和被测构建以验证报告为准。

| 应用 | 首版实测范围 | 当前结果 |
|---|---|---|
| 备忘录 | 是 | 待正式版实测 |
| TextEdit | 是 | 待正式版实测 |
| Safari 网页输入框 | 是 | 待正式版实测 |
| Chrome 网页输入框 | 是 | 待正式版实测 |
| 微信 | 是 | 待正式版实测 |
| 飞书 | 是 | 待正式版实测 |
| VS Code | 是 | 待正式版实测 |
| Terminal | 是 | 待正式版实测；输入不得发送 Return 执行命令 |
| Slack | 否 | 本机未安装，未测试 |
| Cursor | 否 | 本机未安装，未测试 |
| Notion | 否 | 本机未安装，未测试 |
| iTerm2 | 否 | 本机未安装，未测试 |

未测试的四个应用不计入通过数量或成功率分母。它们仍是后续兼容性目标。
macOS 版本、权限状态、输入控件和应用更新都可能影响插入行为。

性能基线为 Apple M5、16 GB 内存、macOS 26.4.1。
未在 M1 等较老机型上测试，较老机型上的识别延迟可能更高。
上述范围决定没有放宽准确率、延迟、录音隐私、安全输入或取消要求。
