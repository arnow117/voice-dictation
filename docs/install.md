# 安装闪说测试版

`v0.1.0-beta.1` 与 `v0.1.0-beta.2` 均面向 Apple silicon（arm64）和 macOS 14 及以上，安装包不含语音模型；首次使用时由应用下载并校验 Qwen3-ASR 0.6B（INT8）。当前 beta.2 分发候选为 `0.1.0/1.0.4`；具体可下载版本以项目 [Release 页面](https://github.com/arnow117/voice-dictation/releases) 为准。测试包使用项目测试签名，未经过 Apple 公证。

1. 下载 ZIP 或 DMG，并用同目录的 `SHA256SUMS.txt` 核对文件校验和。
2. 解压 ZIP，或打开 DMG 后把 `Shanshuo.app` 拖到 `Applications`。DMG 内的 `Applications` 是快捷方式。
3. 首次打开如果 macOS 阻止应用，在 Finder 按住 Control 点按应用并选择“打开”；如仍被阻止，到“系统设置 > 隐私与安全性”确认该应用的打开操作。不要关闭系统安全保护。
4. 按原生引导操作：按需允许麦克风和辅助功能权限，下载语音模型，完成麦克风、快捷键和练习测试。闪说不请求输入监控权限。

麦克风只在按住快捷键听写或主动启动麦克风测试时使用。音频只在内存中做本地识别，不随安装包携带模型权重。模型下载、校验或修复期间不能开始新的听写。

## 在 beta.2 中配置实验性智能整理

智能整理是默认关闭的实验功能，质量和速度尚未达到正式目标，实际结果见下方评测记录。它由使用者在菜单栏“智能整理…”或“设置… > 智能整理”主动设置；本地听写在未开启时不会发送文字到 MiniMax。

1. 阅读数据流向说明，确认只有本次识别文字会发送给所选 MiniMax 端点；音频、屏幕内容和其他应用内容不会发送。设置页会给出该端点的 MiniMax 数据政策入口，应用不承诺零数据保留。
2. 确认后，选择一次性从本机 CC Switch 导入，或把自己的 Key 粘贴到安全输入框。Key 只在本次运行内存中有效，退出后会清除；日常运行不会读取 CC Switch 数据库，界面只显示 Key 末四位。下次启动需重新导入、测试并开启。
3. 选择 `MiniMax-M3.1-Flash`（low effort）或 `MiniMax-M3`，再运行连接测试。该测试只发送固定公开文本，不读取历史、麦克风或真实听写。测试成功后仍须明确开启智能整理。
4. 开启后，正常结果会在插入前完成整理。关闭、替换 Key、切换端点或模型会使旧整理失效；仍有效的会话最多一次回退为原文。网络、Key、额度、限流、超时或结果校验失败同样交付原文并显示固定原因。

按 Esc、进入安全输入框、锁屏、暂停或撤销本次会话所需权限时，整次听写会被丢弃：不会插入、复制或写历史。历史开启时可分别查看和复制识别原文与整理文本。

验证人员可使用稳定测试签名的 beta.2 应用执行 `Shanshuo --formatting-public-eval --out <result.jsonl>`。该命令只读取 checkout 中的公开 60 条夹具，既不接受 Key 参数，也不接受任意听写文本；它会显式只读一次当前用户的 CC Switch 配置，并只在该命令进程内保留凭据。它不读取系统钥匙串，也不复用其他进程的配置。v2 的唯一正式批次仍为 PARTIAL，详情见 [智能整理 v2 评测记录](validation/minimax-formatting-v2.md)；beta.2 不代表质量或延迟验收通过。

本测试版尚有准确率、冷启动、辅助功能和应用兼容性限制，安装前请阅读 [已知问题](known-issues.md)。完整 ASR 准确率事实见 [ASR 验证报告](validation/asr-rms-fix-125650.md)。
