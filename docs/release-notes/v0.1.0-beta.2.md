# 闪说 v0.1.0-beta.2 本地候选说明

此候选在既有本地听写闭环上加入默认关闭的实验性 MiniMax 智能整理。应用版本仍为
`0.1.0`，构建版本为 `1.0.3`。它是本地准备的候选，不代表已发布的新 GitHub
Release，也不覆盖现有 `v0.1.0-beta.1` 资产。

## 智能整理

- 默认关闭。用户从菜单栏“智能整理…”或“设置… > 智能整理”进入，先阅读发送给
  MiniMax 的识别文字、不会发送的音频/屏幕内容，以及对应服务的数据政策；确认后才
  显示 Key 输入和导入操作。
- Key 只在本次运行内存中有效。用户可手动输入，或明确选择一次性从 CC Switch 导入；
  退出后会清除，常态运行不会读取 CC Switch 数据库。连接测试只使用固定公开文本，
  不读取麦克风、历史或真实听写。
- 可选 `MiniMax-M3.1-Flash`（low effort）或 `MiniMax-M3`。冻结的 Flash-low 60 条 EVAL
  为 PARTIAL，未决定最终默认推荐。
- 开启后，仅将本次识别文字发送到用户选择的 MiniMax 端点。音频留在本机。
  应用不承诺零数据保留，设置页提供端点对应的 MiniMax 数据政策入口。
- 正常时，历史会分别保留识别原文和整理文本（如果历史开关已开启）。网络、Key、额度、
  限流、超时或保真检查失败时，仍安全地交付原文并显示固定原因。取消、安全输入、锁屏、
  暂停或所需权限撤销会丢弃整次会话，不插入、不复制也不写历史。

## 评测与验证边界

本候选附带当前 v2 的 60 条公开合成夹具、固定 rubric 和离线 scorer；v1 资产也以版本化
基线保留，不能修改其历史分数。评测命令只读取公开夹具，经同一个 production formatter
运行，输出会保留公开 raw 可见文本和 guard 后的最终文本。2026-10-23 的 v2 唯一冻结网络
批次为 PARTIAL：60 条结果中 51 条有效、42 条正确（82.35%）、最终和 raw 忠实性错误各 1、
9 条超时，P50/P95 为 2175/5001 ms。它未达到正式阈值，不能把质量或延迟标为通过。详细
冻结、统计和限制见 [智能整理 v2 评测记录](../validation/minimax-formatting-v2.md)。本机已完成稳定
签名候选的原生导入、连接测试和开启；用户在备忘录用 Fn 生成了保留前文的编号列表。此单次基本
流程不等于完整端到端性能分布通过。按用户确认先交付实验功能，正式质量和速度目标继续由
[Issue #2](https://github.com/arnow117/voice-dictation/issues/2) 跟踪。

现有 beta.1 的 ASR 准确率、冷启动、辅助功能和 Codex 输入兼容性限制继续适用，详见
[已知问题](../known-issues.md)。安装步骤见 [安装说明](../install.md)。

## 分发边界

候选仍使用项目测试签名，未进行 Apple 公证。准备脚本会生成独立的 arm64 ZIP、带
`Applications` 快捷方式的 DMG 和 `SHA256SUMS.txt`；生成这些本地资产不授权安装、合并
或公开发布。
