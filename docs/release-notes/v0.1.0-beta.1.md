# 闪说 v0.1.0-beta.1 测试版说明

此候选版本提供本地按住说话、录音提示、本地 Qwen3-ASR 识别、安全插入或仅复制回退、原生首次设置、模型下载管理、暂停和七天历史。安装包不含模型权重，首次使用时在应用内下载并校验。

## 安装包

发行资产包含 arm64 `.app` 的 ZIP、带 `Applications` 快捷方式的 DMG 与 `SHA256SUMS.txt`。两种包都附安装说明、已知问题、MIT 许可和第三方声明；应用 Resources 中附完整第三方许可文件。安装步骤见 [install.md](../install.md)。

本版本使用项目测试签名，未进行 Apple 公证。首次打开可能需要在 macOS“隐私与安全性”中明确允许；不要关闭系统安全保护。

## 已知限制

120 条公开音频的实测结果为中文 CER 6.48%（原目标 ≤6%）、英文 WER 6.03%（目标 ≤8%）、中英混说 MER 12.94%（原目标 ≤10%）。本测试版按 REQ-001 DEC-024 披露并接受中文和混说限制，原 NFR-003 仍未通过。完整证据见 [ASR 验证报告](../validation/asr-rms-fix-125650.md)。

八应用正式听写矩阵、完整延迟分布、全屏/多显示器、M1 与独立新账户安装、设置页键盘导航和旁白验证尚未完成。详情见 [已知问题](../known-issues.md)。

智能整理已选择 MiniMax 方向，但尚未接入此测试版；个人词典同样未接入。
