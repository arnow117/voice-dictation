# 测试版已知问题与后续清单

首个测试版优先交付可安装、可实际听写的核心功能（REQ-001 DEC-025）。下列失败和未测试项没有改记为通过。

| 项目 | 当前事实 | 后续处理 |
|---|---|---|
| 中文与中英混说准确率 | 120 条公开原音频中，中文 CER 6.48%（目标 ≤6%）、混说 MER 12.94%（目标 ≤10%）；英文 WER 6.03% 达标。首版按 DEC-024 接受两项限制 | 排查原生与 Python 运行时差异，继续降低错误率 |
| 冷启动 | 安装候选首次启动实测 9.11 秒；此前一个无采样构建为 5.50 秒，均超过 5 秒目标，其他较早样本为 2.12～4.10 秒。不能保证每次 5 秒内就绪 | 后续定位与优化；使用前等待模型和快捷键就绪 |
| 设置页键盘导航与旁白 | Tab/Shift-Tab 焦点移动未证实，用户曾反馈看不到焦点；旁白验证未完成 | 暂缓深入诊断，后续补无障碍验证 |
| 应用兼容性 | 用户确认备忘录热键输入可用，原生练习完成真实麦克风→识别→插入验证；八应用八十次正式矩阵未完成，不能声明 ≥98% 插入成功率 | 补八个本机应用的正式矩阵 |
| Codex 聊天输入框 | 安装版在 Codex 中能录音和识别，但未自动写入；同一安装版用新 Fn／🌐 热键在备忘录中可正常输入，已由用户确认 | 后续修复 Codex 插入兼容性；当前可先在备忘录听写，再手动复制到 Codex |
| 未安装的应用 | Slack、Cursor、Notion、iTerm2 未测试 | 后续环境补齐后验证 |
| 性能与系统场景 | 完整端到端分布、屏幕首帧、全屏/多显示器、外接设备中断等实机检查未完成；生产自动化检查不等于这些真机证据 | 后续集中验证并公布结果 |
| 机型与安装环境 | 仅在 Apple M5 / 16 GB / macOS 26.4.1 上开发测试；M1 和独立新用户账户未验证 | 补旧机型与新账户安装验证 |
| 分发身份 | 使用项目本地测试签名，未做 Apple 公证；macOS 首次打开可能要求在“隐私与安全性”明确允许 | 安装说明列步骤；不关闭系统安全保护 |
| 智能整理质量与延迟 | 2026-10-23 的 v1 冻结批次为 PARTIAL：56 条有效、62.5% 正确、最终忠实性错误 1、4 条超时，P50/P95 为 1901/5000 ms。一次有界规则修正后的 v2 冻结批次仍为 PARTIAL：51 条有效、42 条正确（82.35%）、最终和 raw 保真错误各 1、9 条超时，P50/P95 为 2175/5001 ms；两轮都未达到 ≥95%、0 最终忠实性错误和 1 秒/2.5 秒目标 | 保留 v1 基线、v2 raw/guard 后结果、所有回退和延迟；不复用已见 holdout 调参或重跑。需要产品决定后才可进行新的冻结集和有界方案 |
| 智能整理数据流 | 该功能默认关闭，必须在设置中确认发送识别文字给 MiniMax 后才可开启。音频仍在本机；国内端点的数据政策不等同于已证明的零数据保留 | 保持端点对应政策链接和知情开启；不做 ZDR 承诺 |
| 个人词典 | REQ-003 尚未接入；智能整理不使用个人词典 | 后续单独规划 REQ-003，不在整理候选中扩展词典 |

音频只在本机内存处理。应用仍必须遵守安全输入、取消与剪贴板保护；发现这类关键缺陷时先修复，不能用本清单代替必要检查。

详细准确率报告见 [ASR 验证](validation/asr-rms-fix-125650.md)，应用范围见 [兼容性清单](compatibility.md)。
